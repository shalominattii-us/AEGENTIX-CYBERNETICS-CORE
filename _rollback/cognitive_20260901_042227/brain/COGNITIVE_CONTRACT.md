# AEGENTIX Cognitive Contract

Every intelligence participating in AEGENTIX uses the same lifecycle:

DISCOVER
PLAN
REQUEST
EXECUTE
OBSERVE
VERIFY
REPORT

No model, agent, memory subsystem, or tool is authoritative by itself.

AEGENTIX StateAuthority remains the source of truth.

Memory may provide context.
Models may provide reasoning.
Agents may propose actions.
Tools may produce observations.

Only verified events may advance authoritative state.

CORE INVARIANT:

EVENT -> STATE

Never:

MEMORY -> ASSUMED STATE
MODEL OUTPUT -> FACT
PLAN -> EXECUTION
EXECUTION -> VERIFIED SUCCESS

without evidence.
