8. TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════════

AGENTS STUCK IN RESTARTING:
  Problem:  Agents restarting (1) every few seconds
  Action 1: Check logs: docker logs aegentix-agent-monitoring --tail 20
  Action 2: Verify autonomous_swarm.py: docker run --rm aegentix-agent-monitoring python -c "from autonomous_swarm import AutonomousAgent"
  Action 3: Rebuild: docker build --no-cache -f Dockerfile.monitoring -t aegentix-agent-monitoring .
  Action 4: Restart: docker compose restart agent-monitoring

ELASTICSEARCH WON'T START:
  Problem:  Elasticsearch restarting repeatedly
  Action 1: Check memory: docker stats --no-stream aegentix-elasticsearch
  Action 2: Restart: docker restart aegentix-elasticsearch
  Action 3: If persists: docker logs aegentix-elasticsearch --tail 50

PROMETHEUS ALERTS NOT FIRING:
  Problem:  Alerts defined but not triggering
  Action 1: Check rules: curl http://localhost:9090/api/v1/rules
  Action 2: Check alert state: curl http://localhost:9090/alerts
  Action 3: Verify scrape targets: http://localhost:9090/targets

NATS/ROUTER CONNECTIVITY:
  Problem:  NATS or router showing "unhealthy"
  Action 1: Check logs: docker logs nats / docker logs aegentis-router
  Action 2: Restart: docker restart nats aegentis-router
  Action 3: Verify: docker exec nats nats-cli server list

DISK SPACE ISSUES:
  Problem:  Docker containers failing to start
  Action 1: Check disk: docker system df
  Action 2: Prune: docker system prune -af
  Action 3: Verify: docker system df
