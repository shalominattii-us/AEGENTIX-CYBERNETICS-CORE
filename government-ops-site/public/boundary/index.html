Isolation

One public Worker. No internal route.

A browser talks only to this Worker. The Worker serves its own static files, validates the sample snapshot bundled with those files, and runs the spine’s pure parsing functions in process. It has no binding and no HTTPS client path to the systems below.

Response headers

Every response sets a Content-Security-Policy that allows scripts, styles, images, fonts, and fetches only from this origin. Form navigation and framing are disabled. HTTPS responses also send Strict-Transport-Security and upgrade insecure requests. Other headers: X-Content-Type-Options: nosniff, Referrer-Policy: no-referrer, X-Frame-Options: DENY, same-origin opener and resource policies, and a locked-down Permissions-Policy.

Demo rate limit

POST /api/demo/analyze allows 20 requests per 60 seconds for a client address, counted again inside each isolate and by the Worker rate-limit binding for each Cloudflare location. The platform limit is approximate. If the binding errors, the demo fails closed instead of running anyway. Other routes are read-only.

What a snapshot update is

Replace public/snapshot/opportunities.json with another file that passes the same validator, then deploy a new asset bundle. Do not add a binding that reads the spine database, Foundry’s ledger, or the intake worker’s private storage. The validator rejects email-like values, identifier assignments, and contact fields.

The public Foundry source is at github.com/eaglecrat/Foundry. Following that link is a normal browser navigation. This Worker does not fetch it.
