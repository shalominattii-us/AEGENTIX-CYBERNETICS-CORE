TROUBLESHOOTING GUIDE
════════════════════════════════════════════════════════════════════════════════

If Agents Keep Restarting:
  1. Check logs: docker logs <agent-name>
  2. Verify autonomous_swarm.py in image: docker run --rm <image> python -c "from autonomous_swarm import AutonomousAgent; print('OK')"
  3. Rebuild with --no-cache: docker build --no-cache -f Dockerfile.monitoring -t aegentix-agent-monitoring .
  4. Restart: docker compose restart agent-monitoring

If Elasticsearch Won't Start:
  1. Check memory: docker stats --no-stream aegentix-elasticsearch
  2. Restart: docker restart aegentix-elasticsearch
  3. Logs: docker logs aegentix-elasticsearch --tail 50

If Prometheus Alerts Not Firing:
  1. Check rules: curl http://localhost:9090/api/v1/rules
  2. Check alert state: curl http://localhost:9090/alerts
  3. Verify scrape targets: curl http://localhost:9090/api/v1/targets

If NATS/Router Unhealthy:
  1. Check logs: docker logs nats / docker logs aegentis-router
  2. Restart: docker restart nats aegentis-router
  3. Verify connectivity: docker exec nats nats-cli server list
