# Government Opportunity Engineering Skill

## Purpose
Convert authoritative public opportunities into traceable Treasury Labs requirements, build specifications, Infinite Brain OS plans, capability reuse decisions, and approval-gated internal deliverables.

## Execution order
1. Validate and normalize the opportunity.
2. Preserve provenance and compute the canonical hash.
3. Deduplicate by authoritative source identity.
4. Record amendments, cancellations, awards, and revisions.
5. Parse requirements with source evidence.
6. Generate a reviewable build specification.
7. Index available GitHub, Docker, service, document, CAD, patent, and test assets.
8. Match each requirement to capabilities using reuse, adapt, build, or partner.
9. Generate the Infinite Brain dependency graph across OpenClaw, Nemotron, Hermes, Docker, and Manus.
10. Persist state and emit transactional Cybercore events.
11. Produce tests, deployment artifacts, a runbook, and an execution receipt.

## Required artifacts
- Typed schemas and versioned migrations
- Deterministic normalization and hashing
- Provenance and revision records
- Tests for duplicate and amendment behavior
- Deployment health checks and supervised workers
- Capability registry and match records
- Explicit authorization guards

## Safety boundary
The skill may generate internal drafts, specifications, plans, simulations, evidence packages, patent-development materials, and proposal materials. It must not submit offers, applications, filings, financial commitments, or external representations without explicit user authorization.

## Continuity rule
Every implementation slice must be committed to a branch, documented, tested, represented as a reusable module, and summarized in an execution receipt before moving to the next priority.
